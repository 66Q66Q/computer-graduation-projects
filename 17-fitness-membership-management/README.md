# 智能健身会员系统

## 项目定位

这是一个面向健身房日常运营的会员管理系统，围绕会员、教练、课程、排课、会籍卡和支付记录组织业务信息。系统适合用于健身房前台、教练排课和会员服务管理的综合演示。

## 功能模块

- 用户与会员：用户登录、会员档案、联系方式、会员状态和会籍信息维护。
- 会籍卡：记录会籍类型、有效期、购买情况和会员使用状态。
- 教练管理：维护教练基础资料、擅长方向和可预约安排。
- 课程管理：维护课程信息、课程类型、上课时间和容量。
- 排课预约：安排课程和教练，支持会员查看课程并进行预约。
- 支付记录：记录会籍或课程相关的支付信息和业务状态。
- 设备台账：登记健身设备、位置、使用状态和维护信息。
- 公告统计：发布健身房公告，汇总会员、课程和运营数据。

## 技术实现

- 后端：Java、Spring Boot、MyBatis-Plus、MySQL、JWT。
- 前端：Vue 3、Vue Router、Pinia、Axios、Element Plus、ECharts、Vite。
- 实现方式：前后端分离，后端提供会员、课程、预约和支付记录接口，前端完成管理页面和数据展示。

## 可以做什么

可用于健身房会员管理、瑜伽馆/培训机构课程预约、教练排课和场馆设备管理，也可以扩展签到、私教课、优惠套餐、续费提醒和会员评价。

## 模块说明

| 模块 | 主要内容 |
| --- | --- |
| 会员档案 | 管理会员基础资料、会员状态、入会信息和服务记录。 |
| 会籍卡 | 维护会籍类型、有效期、购买/续费信息和使用状态。 |
| 教练管理 | 管理教练资料、擅长方向和可服务安排。 |
| 课程排期 | 维护课程内容、授课教练、上课时间和课程容量。 |
| 预约管理 | 提供会员预约课程的入口，并记录预约状态和安排。 |
| 支付记录 | 保存会籍或课程相关的支付流水和业务状态。 |
| 设备台账 | 登记健身设备、位置、使用状态和维护信息。 |
| 公告统计 | 发布场馆公告，汇总会员、课程和运营数据。 |

## 典型使用流程

管理人员录入会员和教练资料，配置会籍和课程排期；会员查看可预约课程并提交预约；前台或管理员查看支付和预约记录；设备管理人员维护设备状态，运营人员通过统计页面了解会员及课程情况。

## 技术分工

Spring Boot 提供会员、教练、课程、预约和支付记录接口；MyBatis-Plus 负责数据库访问；MySQL 保存运营数据；JWT 处理登录鉴权；Vue 3、Vue Router 和 Pinia 负责页面路由与前端状态；Axios 负责接口通信；Element Plus 提供管理组件；ECharts 用于运营数据图表；Vite 用于前端开发和构建。
