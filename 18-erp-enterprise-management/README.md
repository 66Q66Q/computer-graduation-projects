# ERP 企业供应链管理系统

## 项目定位

这是一个面向企业基础资料和供应链业务的 ERP 管理系统。系统把客户、供应商、产品、采购、销售和库存等常用业务集中到统一后台，适合作为企业管理类项目的功能展示和二次开发基础。

## 功能模块

- 用户权限：用户、角色、菜单和接口权限管理。
- 供应商管理：维护供应商基础资料、联系人和合作信息。
- 客户管理：维护客户资料和销售往来信息。
- 产品资料：管理产品分类、编码、规格、价格和库存相关信息。
- 采购管理：创建采购订单，记录采购明细、状态和入库关联。
- 销售管理：维护销售订单、销售明细和出库关联。
- 库存管理：查询库存余额、库存交易和采购/销售造成的库存变化。
- 数据概览：以统计卡片和图表展示采购、销售、库存等运营数据。

## 技术实现

- 后端：Java、Spring Boot、Spring Security、JWT、MyBatis-Plus、MySQL。
- 前端：Vue 3、Element Plus、Vite、Axios。
- 实现方式：前后端分离，使用 JWT 和权限配置保护管理端功能，MyBatis-Plus 负责业务数据访问，采购/销售单据与库存交易保持关联。

## 可以做什么

可用于中小企业进销存、供应链业务、商品管理和仓储销售一体化，也可以扩展财务对账、发票、审批流、报表导出、批次管理和多组织管理。

## 模块说明

| 模块 | 主要内容 |
| --- | --- |
| 用户权限 | 管理用户、角色、菜单和接口权限，区分不同岗位的操作范围。 |
| 客户供应商 | 维护客户、供应商、联系人及合作相关基础资料。 |
| 产品资料 | 管理产品分类、编码、规格、价格和库存关联信息。 |
| 采购管理 | 创建采购订单，管理采购明细、订单状态和入库关联。 |
| 销售管理 | 创建销售订单，管理销售明细、订单状态和出库关联。 |
| 库存管理 | 查询库存余额和库存交易，追踪采购入库、销售出库等变化。 |
| 数据概览 | 通过统计卡片或图表查看采购、销售、库存等经营数据。 |

## 典型使用流程

管理员先维护客户、供应商和产品资料；采购人员创建采购订单并完成入库，销售人员创建销售订单并完成出库；库存模块记录业务造成的数量变化，管理人员通过数据概览查看整体经营情况。

## 技术分工

Spring Boot 提供 ERP 业务接口；Spring Security 与 JWT 负责身份认证和权限控制；MyBatis-Plus 负责数据访问；MySQL 保存基础资料、采购、销售和库存数据；Vue 3、Element Plus、Vite 和 Axios 构建管理端页面并连接后端接口。
