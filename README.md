## 技术方向

- **Java Web 全栈**：Spring Boot、Spring Security、JWT、MyBatis/MyBatis-Plus、JPA、MySQL、Redis。
- **前端与管理后台**：Vue 3、Vue Router、Pinia、Element Plus、Axios、ECharts、Vite、TypeScript。
- **微信小程序**：原生小程序页面、REST API 通信、商品/预约/服务类业务流程。
- **人工智能与数据分析**：PyTorch、scikit-learn、Pandas、NumPy、Streamlit、Flask、知识图谱、RAG、推荐算法。
- **工程化与部署**：Maven、npm、SQL 初始化脚本、部署说明和测试代码。
